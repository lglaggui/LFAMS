FAMS v0.0216 — Validation Report

Baseline
- Source baseline: v0.0215 Fund Opening Classification package.
- Release: v0.0216 — Fund Breakdown Wrapping and Unified MAIFIP Monthly Reconciliation.

Implemented
- Fund Source text wraps inside its own grid column in both AICS and MAIFIP dashboards.
- MAIFIP worksheet, print view, and CSV now call the same maifip_monthly_fund_reconciliation() helper.
- The shared helper applies the established disbursement precedence: live RELEASED detail rows when present; saved monthly summary only when no live RELEASED rows exist.
- Ending balance is calculated as opening balance + actual fund downloads + audited adjustments - authoritative released assistance.
- Print no longer subtracts only live detail amounts when a historical monthly summary is authoritative.
- Worksheet and print display adjustments separately.
- CSV exports opening balance, downloads, adjustments, released assistance, ending balance, source selection, detail released total, detail client count, and authoritative client count.
- Excel export includes the full fund balance components and retains worksheet-local edits.
- Existing MAIFIP facility authorization structure remains unchanged and has source-level assertions.
