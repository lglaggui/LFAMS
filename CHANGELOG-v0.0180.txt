VERSION 0.0180

VISUAL REGRESSION + PAGEVIEW / CSS CASCADE STANDARDIZATION

1. SHARED PAGEVIEW GEOMETRY
- Standardized AICS and MAIFIP Pageview padding on all four edges using one shared responsive gutter variable.
- Desktop (>1100px): 28px on every edge.
- Medium/tablet (768–1100px): 22px on every edge.
- Compact tablet/mobile (561–800px): 16px on every edge.
- Narrow mobile (<=560px): 12px on every edge.
- Pageview outer margins are explicitly zero on all axes.
- First and last direct content children have zero block-axis margins so their margins do not stack on top of the Pageview gutter.
- Footer inset follows the same horizontal gutter; the fixed footer's reserved height remains part of the main-column layout.
- Popup and print Pageviews retain their intentional zero-padding exception.

2. MEASURED HEADER RESERVATION FIX
- Added the AICS main-content selector to the canonical shared-shell reservation rule.
- This removes the higher-specificity legacy AICS 76px/68px guessed top offset that could override the actual measured header height.
- Both AICS and MAIFIP now reserve the runtime-measured fixed header height before Pageview begins.

3. PAGE RHYTHM / WORKSPACE ALIGNMENT
- Shared page heading gap: 12px.
- Shared page heading bottom spacing: 16px.
- Shared toolbar/filter/action-row gap: 10px.
- Common card/panel inset: 18px desktop, 16px medium/tablet, 13px narrow mobile.
- Removed an obsolete AICS dashboard width cap/centering rule that competed with the shared full-width dashboard layout.
- Kept program-specific page components, table column definitions, form behavior, and business workflows intact.

4. CSS CASCADE CLEANUP
- Removed superseded AICS and MAIFIP Pageview frame declarations now owned by core/shared-shell.css.

- No empty CSS rules or byte-identical duplicate rule blocks detected in the audited CSS.
