MANUAL REVIEW FINDINGS / TEST REQUIREMENTS:
1. Portal selector is `portal/select-system.php`; its POST selection requires the portal CSRF token and an authenticated LPGMA identity in the portal session.
2. AICS record visibility is intentionally centralized across SWAD offices. Mutation checks remain office-scoped; test both permitted cross-office viewing and denied cross-office editing/status/deletion.
3. MAIFIP records and CSV exports must remain qualified by the authenticated active facility. Test identifier replay against a second facility.
4. AICS and MAIFIP import paths require independent negative tests for cross-workspace data, duplicate Control No./legacy number, duplicate rows, locked/finalized records, malformed uploads, oversized uploads and stale preview submissions.
5. Offline synchronization is MAIFIP-only in this package. Test CREATE vs UPDATE permissions, facility binding, replayed client_change_id, duplicate payload mismatch, stale record_version, conflict resolution, and the 100-change request cap.
6. Retryable business mutations must be tested for atomic business-write + idempotency/audit/history behavior, including rollback on injected failure.
7. CSV record/report exports and browser-generated Excel sheets now neutralize spreadsheet formula prefixes in text cells. Browser-generated AICS/MAIFIP sheet exports and print/PDF actions now call workspace-specific POST+CSRF+export-capability audit endpoints before generating the file. Test payloads beginning with =, +, -, @, tab and leading whitespace before formula prefixes in Excel and LibreOffice.
8. AICS expiry is an application-triggered system batch: it locks expired WAITING records, increments record versions, writes status history and system audit events in a transaction. It is not a separate cron worker. Test repeated concurrent page requests and ensure each record is cancelled/audited once.
9. No dedicated scheduled import/export/offline worker was found in the registered PHP workspace endpoints. Deployment-level cron, hosting scheduler, queue workers and external scripts still require operator inventory.

REQUIRED STAGING ACCOUNT MATRIX:
- AICS local SWAD Social Worker: own-office mutation allowed; other-office read visibility according to Region II policy; other-office mutation denied.
- AICS LPGMA Administrator: authorized cross-office administration, but workspace permission checks still apply.
- MAIFIP facility Social Worker / Encoder: own-facility records only; disallowed create/edit/status operations denied according to role capabilities.
- MAIFIP LPGMA Administrator: authorized central administration; verify cross-facility policy and no AICS permission inheritance.
- Central LPGMA non-admin: only explicit target-workspace capabilities; no administrator escalation or role inheritance.
