Recommended frontend consolidation order:
1. Extract shared tokens and primitives into core/shared-components.css and core/uniform.css.
2. Separate AICS/MAIFIP page-specific layout styles from shared shell styles.
3. For each duplicate selector, compare declarations, specificity, source order, and enclosing media/support conditions before merging.
4. Remove only confirmed dead declarations after desktop/tablet/mobile screenshot comparison.
5. Add CSS ownership comments or component boundaries to prevent future cascade drift.
